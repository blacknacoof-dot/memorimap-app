## 🔍 데이터 수집 방법론

### 1. 웹 크롤링/스크래핑

#### 대상 플랫폼
| 플랫폼 | 수집 가능 데이터 | 우선순위 |
|--------|-----------------|----------|
| **네이버 지도** | 업첼명, 주소, 연락처, 이미지, 리뷰 | P0 |
| **카카오맵** | 업첼명, 주소, 연락처, 이미지 | P0 |
| **Google Places** | 해외 사용자용 영문 정보 | P2 |
| **장례식장 전문 사이트** | 가격 정보, 시설 정보 | P1 |

#### 크롤링 전략
```python
# 네이버 지도 API 활용
# 1. 키워드 검색: "[지역명] 장례식장"
# 2. 업체 목록 수집
# 3. 상세 페이지 크롤링 (이미지, 연락처)
# 4. 데이터 정제 및 DB 저장
```

**주의사항:**
- robots.txt 준수
- 요청 간격 1-2초 유지 (IP 차단 방지)
- API 사용량 제한 확인

### 2. 공공데이터 API 활용

| 데이터셋 | 제공처 | 활용 가능성 |
|----------|--------|-------------|
| **장사시설 현황** | 행정안전부 | 전국 장례식장 목록 |
| **의료기관 정보** | 건강보험심사평가원 | 병원장례식장 정보 |
| **상조업체 정보** | 공정거래위원회 | 상조업체 등록 현황 |

**장점:**
- 물둘한 공식 데이터
- 정기 업데이트
- API 호출 제한 적음

### 3. 수동 데이터 수집 (Manual Curation)

#### 대상 업체
- 대형 병원 장례식장 (삼성서울병원, 서울아산병원 등)
- 전문 상조업체 (병원상조, 대명상조 등)
- 지방 소규모 장례식장

#### 수집 방법
1. **전화 문의**: 직접 연락하여 최신 정보 확인
2. **홈페이지 방문**: 공식 홈페이지 정보 수집
3. **현장 방문**: 직접 촬영 및 정보 확인 (지역별)

### 4. CSV 데이터 정제 및 병합

#### CSV → DB 병합 전략
```sql
-- 1. CSV 데이터 임시 테이블 생성
CREATE TEMP TABLE csv_facilities AS 
SELECT * FROM read_csv_auto('facilities.csv');

-- 2. 중복 업체 확인 (유사도 기반)
SELECT db.name, csv.name, similarity(db.name, csv.name)
FROM facilities db
JOIN csv_facilities csv 
  ON similarity(db.name, csv.name) > 0.8;

-- 3. 신규 업체 식별 및 추가
INSERT INTO facilities (name, address, phone, ...)
SELECT name, address, phone, ...
FROM csv_facilities csv
WHERE NOT EXISTS (
  SELECT 1 FROM facilities db 
  WHERE similarity(db.name, csv.name) > 0.9
);
```
