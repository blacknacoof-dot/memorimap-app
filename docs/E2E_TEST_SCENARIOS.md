## 5. 크로스 롤 E2E 시나리오 (통합)

### 시나리오 A: 파트너 입점 → 승인 → 대시보드 접근

```
1. [일반유저] 파트너 입점 신청 (/#/partner-inquiry)
   → partner_inquiries INSERT (status: pending)

2. [슈퍼관리자] /#/super-admin > admissions 탭
   → 대기 목록에 신청 건 표시 확인

3. [슈퍼관리자] 승인 클릭
   → Edge Function → approve_partner_transaction RPC
   → facilities 생성, partners 생성, profiles.role 변경
   → 이메일 알림 발송 (Resend)
   → user_notifications INSERT

4. [승인된 유저] 재로그인
   → 사이드메뉴에 "대시보드" 메뉴 표시 확인
   → /#/facility-admin 또는 PartnerDashboard 접근 가능

5. [승인된 유저] 대시보드에서 시설 정보 확인
   → 시설명, 예약/상담 데이터 표시
```

### 시나리오 B: 상조 AI 상담 → 예약 → 관리자 확인

```
1. [일반유저] 상조 업체 페이지 (/#/funeral-company)
   → 업체 목록 표시

2. [일반유저] 프리드라이프 > AI 상담 시작
   → SangjoConsultationModal 열림
   → AI 대화 진행

3. [일반유저] 상담 완료
   → consultations INSERT (facility_id 연결)

4. [일반유저] 예약 진행
   → reservations INSERT (status: pending)

5. [상조관리자] PartnerDashboard > consultations 탭
   → 해당 상담 건 표시 확인

6. [상조관리자] reservations 탭
   → 해당 예약 건 표시, 승인/거절 가능
```

### 시나리오 C: 일반 시설 상담 → 예약 → 관리자 확인

```
1. [일반유저] 지도에서 장례식장 선택
   → FacilitySheet 표시

2. [일반유저] 상담 신청 > 폼 작성 > 제출
   → consultations INSERT

3. [일반유저] 예약하기 > 날짜/시간 선택 > 제출
   → reservations INSERT (status: pending)

4. [업체관리자] /#/facility-admin > 대기중 탭
   → 예약 건 표시

5. [업체관리자] 예약 승인
   → status → confirmed

6. [일반유저] 마이페이지 > 확정 예약 탭
   → 승인된 예약 확인
```

### 시나리오 D: 슈퍼관리자 전체 대시보드 순회

```
1. [슈퍼관리자] /#/super-admin 접속
2. monitoring 탭 → 계약/운영 현황 로드 확인
3. admissions 탭 → 입점 신청 목록 확인
4. facilities 탭 → 시설 목록 + 검색 확인
5. users 탭 → 유저 목록 + 권한 변경 확인
6. subs 탭 → 구독 현황 확인
7. revenue 탭 → 결제 내역 확인
8. notices 탭 → 공지 CRUD 확인
9. logs 탭 → 활동 로그 표시 확인
10. communication 탭 → 소통센터 표시 확인
11. system_settings 탭 → 설정 조회/변경 확인
```
