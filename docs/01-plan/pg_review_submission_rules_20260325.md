# PG Review Submission Rules

작성일: 2026-03-25
목적: KCP / KG이니시스 심사 제출 시 사이트 노출 기준과 제출 기준을 통일하기 위한 실행 메모다.

## 1. URL policy

- 심사는 가능하면 운영 URL 기준으로 진행한다.
- `test`, `staging`, `dev` 성격 URL은 보조 참고 링크로만 사용한다.
- 운영 도메인이 준비되어 있다면 심사 URL도 운영 도메인으로 통일한다.

## 2. Cross-PG consistency

- `NHN KCP`, `KG이니시스` 두 PG에 보여주는 사이트 정보는 동일 기준으로 유지한다.
- 상품명, 가격, 환불정책, 사업자 정보가 PG마다 다르게 보이면 안 된다.
- PG사와 메일할 때는 `pgs@portone.io`를 항상 참조한다.

## 3. Required exposure on site

- 메인 또는 고객센터 경로에서 사업자 정보 접근 가능
- 결제 직전 요금제 화면에서 사업자 정보 접근 가능
- 결제 직전 요금제 화면에서 `이용약관`, `개인정보처리방침`, `환불/해지 정책` 접근 가능

## 4. Required business info

사이트에 아래 항목이 보여야 한다.

- 상호명
- 대표자명
- 사업자등록번호
- 사업장 주소
- 전화번호
- 이메일
- 통신판매업신고 번호

## 5. Memorimap current status

- 고객센터 경로에 법적 정보/사업자 정보 접근 경로 추가 완료
- 시설/상조 요금제 결제 화면에 법적 정보/사업자 정보 접근 경로 추가 완료
- 개인 요금제 결제 화면에 법적 정보/사업자 정보 접근 경로 추가 완료
- 사업자 정보 최신값 반영 완료
