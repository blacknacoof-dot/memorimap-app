# PortOne 신청 체크리스트 (Memorimap)

작성일: 2026-03-25
목적: Memorimap 결제/구독 운영을 위해 PortOne 신청 전에 필요한 항목을 빠르게 점검한다.

## 1. 신청 방향

- 우선 신청: `신용카드 정기결제`
- 선택 신청: `신용카드 일반결제`
- 권장 판단:
  - 개인/시설 구독만 먼저 운영하면 `정기결제` 우선
  - 예약금, 단건 결제, 추가 결제 가능성이 있으면 `일반결제`도 함께 신청

## 2. 서비스 결제 범위 확정

- 개인 요금제: 월 구독 여부 확정
- 시설 요금제: 월 구독 여부 확정
- 연간 요금제: 이번 신청 범위 포함 여부 확정
- 상조 상품: 구독형인지 계약형인지 확정
- 예약금/단건 결제: 운영 계획 유무 확정

## 3. 사업자/정산 정보

- 사업자명
- 사업자등록번호
- 대표자명
- 업태/종목
- 정산 계좌 정보
- 고객센터 이메일
- 고객센터 전화번호
- 환불 정책
- 해지 정책

## 4. 운영 도메인 정리

- 운영 도메인 확정
  - `memorimap.kr`
  - `www.memorimap.kr`
- 실제 결제에 사용할 배포 도메인 확정
- PortOne/PG 화이트리스트 등록 대상 도메인 목록 정리

## 5. PortOne/PG 확인 질문

- 선택한 PG가 `신용카드 정기결제`를 지원하는지
- 결제창 방식인지 API 방식인지
- PC/모바일 모두 동일하게 지원하는지
- 일반결제와 정기결제를 같은 PG로 처리 가능한지
- 테스트 키/운영 키 발급 절차가 어떻게 되는지
- 운영 도메인 추가 등록 절차가 어떻게 되는지

## 6. 개발 선행 준비

- 결제 성공 후 서버 검증 API 존재 여부 확인
- 구독 상태 반영 로직 정리
- 결제 이력 저장 구조 확인
- `billing_cycle` 확장 필요 여부 정리
- 요금제 표시명(`display_plan_name`) 분리 필요 여부 정리

## 7. 운영 전 점검

- 테스트 결제 가능 여부
- 테스트 정기결제 등록/해지 가능 여부
- 결제 실패 시 사용자 메시지 확인
- 결제 후 슈퍼관리자/운영 화면 반영 확인
- 결제 이력과 시설명/구독 정보 매핑 확인

## 8. Memorimap 권장 결론

- 현재 우선순위: `신용카드 정기결제 신청`
- 단, 예약금/단건 결제를 곧 붙일 계획이면 `신용카드 일반결제`도 같이 신청
- 개발 순서:
  1. PortOne 신청
  2. 내부 요금제/구독 구조 개발
  3. 승인 후 운영 키 연결
  4. 실결제 검증
  5. 점진 배포
