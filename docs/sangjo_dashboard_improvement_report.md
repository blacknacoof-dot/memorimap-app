## 2. 문제 진단

### 2.1 "구독/매출" 탭 — 명칭과 내용 불일치

**현재 문제**:
- "매출"이라는 표현은 상조 업체가 플랫폼에서 직접 결제를 받는 구조를 암시
- 실제로는 **플랫폼 이용료(구독료)**를 내는 구조
- 상조 업체의 실제 매출은 외부에서 발생 (고객 장례 계약금)
- KPI 카드의 "총 상담", "총 예약" 수치가 매출과 직접 연결되지 않음

**개선 방향**:
- 탭 이름: "구독/매출" → **"구독 요금제"** 또는 **"요금제 관리"**
- 매출 차트 제거 또는 **"활동 통계"**로 변경
- 결제 내역은 "구독 결제 내역"으로 명확히

### 2.2 "실시간 채팅" — 상조 업체에 불필요

**불필요 이유**:
- 상조 업체는 AI 자동상담 → 계약 전환이 핵심 비즈니스 플로우
- 실시간 1:1 채팅은 장례식장(시설관리자)에 더 적합
- 상조 업체 상담은 전화 기반이 주류 (긴급성 높음)
- `partner_conversations` 테이블에 데이터가 거의 없을 가능성 높음
- STARTER 요금제에 이미 "AI 24시간 자동상담"이 포함 → 별도 채팅 불필요

**개선 방향**:
- 실시간 채팅 탭 제거 (상조 대시보드에서만)
- AI 상담 현황은 "상담 관리" 탭에 통합

### 2.3 업그레이드 경험 부족

**현재 문제**:
- 요금제 변경은 "구독/매출" 탭 내부에서만 접근 가능
- 업그레이드 혜택이 직관적으로 보이지 않음
- 수수료 차이(10%→8%→5%)가 가장 큰 인센티브인데 강조 부족
- 무료 체험 → 유료 전환 동선 없음

## 3. 개선 제안

### 3.1 탭 구조 재편 (6개 → 5개)

| 순서 | 탭 이름 | 내용 | 변경사항 |

| 2 | **운영 현황** | 칸반보드 (장례 진행 관리) | 변경 없음 |

### 3.3 업그레이드 동선 확장 (3가지 진입점)

현재는 요금제 탭에서만 접근 가능. 아래 3가지 추가 진입점 제안:

#### A. 대시보드 상단 배너 (기능 제한 시)
```
┌──────────────────────────────────────────────┐
│ 💎 PROFESSIONAL로 업그레이드하면              │
│    수수료 2%p 절감 + 우선 노출 + 전담 CS     │
│    [자세히 보기]                    [닫기]    │
│                                              │
│ (이번 달 추가 수수료 약 ₩42만 발생 중)        │
└──────────────────────────────────────────────┘
```

**표시 조건**:
- STARTER 사용 중 + 월 상담 20건 이상 → PROFESSIONAL 추천
- PROFESSIONAL 사용 중 + 월 상담 50건 이상 → ENTERPRISE 추천
- 닫으면 7일간 미표시

#### B. 기능 사용 시점 잠금 화면 (Feature Gate)
```
┌──────────────────────────────────┐
│  🔒 이 기능은 PROFESSIONAL      │
│     요금제부터 이용 가능합니다    │
│                                  │
│  포함 기능:                      │
│  ✓ 고급 CRM                     │
│  ✓ 실시간 전환율 대시보드         │
│  ✓ 주간 리포트                   │
│                                  │
│  [요금제 업그레이드]  [나중에]    │
└──────────────────────────────────┘
```

**잠금 대상 기능**:
| 기능 | STARTER | PROFESSIONAL | ENTERPRISE |
|------|---------|-------------|------------|
| AI 자동상담 | ✅ | ✅ | ✅ |
| 기본 상담/예약 관리 | ✅ | ✅ | ✅ |
| 운영 칸반보드 | ✅ | ✅ | ✅ |
| 기본 리포트 | ✅ | ✅ | ✅ |
| 우선 노출 | ❌ | ✅ | ✅ |
| 고급 CRM | ❌ | ✅ | ✅ |
| 실시간 전환율 대시보드 | ❌ | ✅ | ✅ |
| 전담 CS | ❌ | ✅ | ✅ |
| 메인 배너 광고 | ❌ | ❌ | ✅ |
| 자동 계약 체결 | ❌ | ❌ | ✅ |
| 1:1 전담 매니저 | ❌ | ❌ | ✅ |
| API 연동 | ❌ | ❌ | ✅ |

#### C. 월간 리포트 이메일 하단
```
이번 달 상담 42건 중 12건이 계약으로 전환되었습니다.
PROFESSIONAL 요금제의 고급 CRM을 사용하면 전환율을 평균 15% 높일 수 있습니다.
[업그레이드 알아보기]
```

### 3.4 수수료 절감 시뮬레이터 (신규 기능 제안)

상조 업체에게 가장 직관적인 업그레이드 동기는 **수수료 절감**입니다.

```
┌─── 수수료 절감 시뮬레이터 ───────────────────┐
│                                              │
│  월 평균 계약 건수:  [ 30건 ▼ ]              │
│  건당 평균 계약금:   [ ₩500만 ▼ ]            │
│                                              │
│  ┌────────────┬──────────┬──────────┐       │
│  │            │ 현재     │ 업그레이드│       │
│  │ 요금제     │ STARTER  │ PROFESS. │       │
│  │ 수수료율   │ 10%      │ 8%       │       │
│  │ 월 수수료  │ ₩1,500만 │ ₩1,200만 │       │
│  │ 구독료     │ ₩300만   │ ₩800만   │       │
│  │ 총 비용    │ ₩1,800만 │ ₩2,000만 │       │
│  │ 순 절감    │ —        │ -₩200만  │       │
│  └────────────┴──────────┴──────────┘       │
│                                              │
│  ⚠️ 월 40건 이상부터 PROFESSIONAL이 유리합니다│
│                                              │
│  💡 손익분기점: 월 34건 (건당 ₩500만 기준)    │
│                                              │
└──────────────────────────────────────────────┘
```

**핵심 가치**: 업체가 스스로 "언제 업그레이드하면 이득인지" 판단 가능

## 5. 요약

| 항목 | 현재 | 개선 후 |
|------|------|---------|
| 탭 이름 | 구독/매출 | **요금제 관리** |
| 실시간 채팅 | 있음 (미사용) | **제거** |
| 업그레이드 진입점 | 1곳 (요금제 탭) | **4곳** (탭+배너+게이트+이메일) |
| 수수료 비교 | 없음 | **시뮬레이터** |
| 활동 지표 | 매출 차트 (부정확) | **활동 통계** (상담/계약/예약/완료) |

**핵심 메시지**: 상조 업체는 "매출을 올리는 곳"이 아니라 "플랫폼 비용을 최적화하는 곳"입니다. 수수료 절감이 가장 강력한 업그레이드 동기이며, 이를 직관적으로 보여주는 것이 전환율의 핵심입니다.
