# 고양시 장례식장 DB 시드 초안

작성일: 2026-04-11  
대상: 추모맵 고양시 초기 장례식장 데이터 구축

## 사용 원칙

- 아래 목록은 `웹 공개 자료 기준으로 운영 흔적이 확인되는 시설`만 우선 정리했다.
- `공식 홈페이지`, `병원 장례식장 안내`, `e하늘 기반 정보 페이지`를 우선 참고했다.
- 비용, 빈소 수, 주차 대수는 시점에 따라 달라질 수 있으므로 실제 게시 전 `전화 확인`이 필요하다.
- 명칭이 다른 경우는 `표시명`과 `운영 주체명`을 분리해 관리하는 편이 낫다.

## 필드 제안

| 필드 | 설명 |
| --- | --- |
| display_name | 추모맵에 노출할 시설명 |
| legal_or_alt_name | 운영 법인명 또는 대체 표기 |
| district | 덕양구 / 일산동구 / 일산서구 |
| address | 도로명주소 |
| phone | 대표 전화 |
| type | hospital / private |
| rooms | 빈소 수 |
| capacity_note | 안치능력 또는 빈소 규모 메모 |
| parking | 주차 정보 |
| dining | 식당 여부 |
| convenience | 매점 / 대기실 / 장애인 편의시설 메모 |
| price_range | 대표 빈소 가격 범위 또는 핵심 가격 |
| status | ready / verify_needed |
| notes | 운영 포인트 / CTA 포인트 |
| sources | 확인 출처 |
