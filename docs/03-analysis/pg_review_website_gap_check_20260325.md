# PG Review Website Gap Check (Memorimap)

작성일: 2026-03-25
목적: PG 심사 기준 관점에서 현재 코드베이스 기준 웹사이트 공개 정보의 부족 항목을 점검한다.

## Summary

현재 코드 기준 판단:

- 요금제/가격 노출: 있음
- 고객센터 연락처/문의 수단: 있음
- 이용약관: 존재하지만 회원가입 모달 내부 노출 수준
- 개인정보처리방침: 존재하지만 회원가입 모달 내부 노출 수준
- 환불/해지 정책: FAQ 수준의 간접 안내만 존재
- 사업자 정보 공개: 확인 불가
- 공개형 법적 페이지 링크 구조: 확인 불가

결론:

- 현재 상태로는 PG 심사 제출용 공개 정보가 충분하다고 보기 어렵다.
- 특히 `사업자 정보`, `공개형 이용약관 페이지`, `공개형 개인정보처리방침 페이지`, `명시적 환불/해지 정책`이 우선 보강 대상이다.

## Detailed findings

### 1. Website accessibility

- 코드베이스만으로 운영 사이트 실접속 여부는 확인하지 못함
- 운영 도메인에서 실제 접속 검증 필요

판정: `추가 확인 필요`

### 2. Business information

확인 결과:

- 사업자등록번호, 대표자명, 사업장 주소 같은 공개 사업자 정보는 코드 검색 기준 확인하지 못함
- 고객센터 연락처는 `components/StaticViews.tsx`에서 `031-975-3335` 노출 확인

판정: `미흡`

필요 조치:

- 푸터 또는 별도 페이지에 사업자명, 대표자명, 사업자등록번호, 주소, 고객센터 연락처 명시

### 3. Terms of service

확인 결과:

- `components/SignUpModal.tsx` 안에 `TERMS_OF_SERVICE` 텍스트가 존재
- 회원가입 시 동의 UI도 존재
- 하지만 공개 URL 또는 별도 페이지 형태는 확인하지 못함

판정: `부분 충족`

필요 조치:

- 로그인 없이 접근 가능한 `이용약관` 페이지 또는 모달 외 독립 화면 제공
- 푸터/사이드 메뉴/결제 화면에서 직접 접근 가능하게 연결

### 4. Privacy policy

확인 결과:

- `components/SignUpModal.tsx` 안에 `PRIVACY_POLICY` 텍스트가 존재
- 회원가입 시 동의 UI도 존재
- 하지만 공개 URL 또는 별도 페이지 형태는 확인하지 못함

판정: `부분 충족`

필요 조치:

- 로그인 없이 접근 가능한 `개인정보처리방침` 페이지 제공
- 푸터/회원가입/결제 화면에서 접근 가능하게 연결

### 5. Refund and cancellation policy

확인 결과:

- `components/StaticViews.tsx` FAQ에 환불 관련 답변 존재
- 현재 문구는 `시설별 환불 규정이 상이합니다. 계약 전 해당 시설에 확인` 수준
- `components/SubscriptionPlans.tsx` FAQ에는 해지 가능/환불 문의 안내만 존재
- 포트원/구독 관점의 명시적 환불/해지/청약철회 정책 페이지는 확인하지 못함

판정: `미흡`

필요 조치:

- 정기결제 해지 방법
- 환불 가능/불가 조건
- 중도 해지 시 처리 기준
- 청약철회 또는 환불 문의 방법

위 내용을 별도 정책 페이지나 명확한 섹션으로 공개

### 6. Products and pricing

확인 결과:

- `components/SubscriptionPlans.tsx`에 시설 구독 요금제와 가격 존재
- `components/PersonalSubscriptionPlans.tsx`도 존재하나 이번 점검에서는 세부 확인 생략
- FAQ에서 결제 관련 안내 존재

판정: `충족`

보완 권장:

- 운영 사이트에서 로그인 없이 가격표 접근 가능 여부 확인
- 월 구독/정기결제 문구를 더 명확히 정리

## Evidence

- `components/StaticViews.tsx`
- `components/SubscriptionPlans.tsx`

## Priority actions

1. 공개형 `이용약관` 페이지 추가
2. 공개형 `개인정보처리방침` 페이지 추가
3. `환불/해지 정책` 페이지 추가
4. 푸터 사업자 정보 노출 추가
5. 운영 도메인에서 가격표/법적 문서 접근성 확인

## Final assessment

PG 심사 기준으로 보면 현재 사이트는 `결제 상품 노출`과 `고객센터 수단`은 어느 정도 있으나, 법적/사업자 공개 정보가 부족하다.

제출 전 최소 완료 조건:

- 사업자 정보 공개
- 이용약관 공개 페이지
- 개인정보처리방침 공개 페이지
- 환불/해지 정책 공개 페이지
