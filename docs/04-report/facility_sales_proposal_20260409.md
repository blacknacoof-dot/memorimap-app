# 메모리맵 시설 입점 영업 제안서 문안

## 1. 제안 제목

메모리맵 입점 제안  
장례·추모 고객이 바로 찾고 비교하고 상담하는 디지털 접점

## 2. 제안 배경

장례·추모 고객은 대부분 급한 상황에서 지역, 가격, 시설 정보, 후기, 상담 가능 여부를 빠르게 확인하려고 합니다.  
하지만 실제 시장에서는 정보가 흩어져 있고, 가격과 서비스 범위가 명확하게 정리되어 있지 않은 경우가 많습니다.

메모리맵은 이런 문제를 해결하기 위해 만들어진 장례·추모 의사결정 플랫폼입니다.  
시설은 메모리맵에 입점함으로써 단순 노출이 아니라 `비교 가능한 신뢰 페이지`, `상담/예약 접수 채널`, `운영 성과 확인 도구`를 동시에 확보할 수 있습니다.

## 3. 메모리맵이 제공하는 가치

### 1. 고객이 찾는 순간 바로 연결됩니다

- 지역 기반 지도/목록 노출
- 시설 상세 정보, 사진, 가격, 후기 제공
- 상담 및 예약 접수 연결

### 2. 시설 신뢰도를 높일 수 있습니다

- 가격과 패키지 정보 구조화
- 사진과 FAQ 정리
- 리뷰 확인 및 응대 기능
- 공식 입점/검수 기반 운영 가능

### 3. 운영 효율을 높일 수 있습니다

- 전화 중심 문의를 구조화된 상담으로 전환
- 상담/예약 이력 확인
- 응답률과 문의 현황 파악
- 향후 통계 기반 운영 개선 가능

## 4. 메모리맵 입점 시 기대효과

- 지역 내 신규 고객 접점 확대
- 가격/서비스 비교 과정에서 선택 가능성 상승
- 기존 소개/지인 의존 구조 외 추가 유입 채널 확보
- 디지털 정보 부족으로 인한 이탈 감소
- 상담 및 예약 접수의 체계화

## 5. 추천 입점 대상

- 지역 대표 장례식장
- 봉안당/추모공원/수목장 시설
- 디지털 홍보는 약하지만 서비스 경쟁력이 있는 중소 시설
- 지점 확장을 고려하는 체인형 운영사

## 6. 제공 항목 예시

- 시설 기본 정보 페이지 생성
- 사진 및 소개 콘텐츠 등록
- 가격/패키지 정보 정리
- 후기 노출
- 상담/예약 접수
- 관리자 전용 운영 화면 제공

## 7. 입점 방식

### 기본 입점

- 시설 정보 등록
- 사진/소개 등록
- 기본 노출

### 운영형 입점

- 후기 관리
- 가격/패키지 관리
- 상담 운영
- 통계/성과 확인

### 확장형 입점

- 우선 노출
- 복수 지점/담당자 운영
- 권역 단위 성과 관리

## 8. 메모리맵의 차별점

- 단순 광고 배너가 아니라 실제 비교/상담 흐름 안에서 노출
- 가격, 사진, 후기, 상담이 한 화면에서 연결
- 지도와 리스트를 함께 활용한 탐색
- 향후 응답속도, 전환, 운영성과까지 연결 가능한 구조

## 9. 도입이 쉬운 이유

초기에는 복잡한 설정 없이 시작할 수 있습니다.

- 기본 자료만 전달하면 등록 지원 가능
- 사진/가격표/소개 문구 정리 지원 가능
- 운영 담당자가 없어도 시작 가능

## 10. 이런 시설에 특히 적합합니다

- 지역 내 경쟁이 심해 온라인 차별화가 필요한 시설
- 전화 문의는 많지만 정보 전달이 비효율적인 시설
- 가격/서비스 경쟁력은 있으나 디지털 노출이 약한 시설
- 브랜드 신뢰를 온라인에서 강화하고 싶은 시설

## 11. 제안 문구 예시

안녕하세요. 메모리맵은 장례·추모 고객이 지역별 시설을 비교하고 상담·예약까지 진행할 수 있도록 만든 플랫폼입니다.

현재 많은 유가족과 보호자분들이 급한 상황에서 시설 정보, 가격, 사진, 후기, 상담 가능 여부를 한 번에 확인할 수 있는 채널을 찾고 있습니다. 메모리맵은 귀 시설이 이런 고객과 가장 빠르게 연결될 수 있도록 돕습니다.

입점하시면 단순 노출이 아니라 시설 소개, 사진, 가격, 후기, 상담 접수, 예약 흐름까지 하나의 구조 안에서 운영하실 수 있습니다. 또한 향후에는 문의 현황과 응답 성과까지 확인할 수 있어 디지털 운영 효율도 함께 높일 수 있습니다.

초기에는 필요한 자료를 전달해 주시면 등록을 지원해 드릴 수 있어 도입 부담도 크지 않습니다.  
귀 시설이 온라인에서 더 신뢰 있게 선택될 수 있도록 함께 만들고 싶습니다.

미팅 가능하신 시간 주시면 서비스 화면과 입점 방식, 운영 예시를 간단히 설명드리겠습니다.

감사합니다.
