# 메모리맵 실행 일정표 및 매출 KPI 시트

## 1. 운영 원칙

- 초기 90일은 `입점 기반 구축`이 우선
- 광고비 확대보다 `입점 품질`과 `전환 사례` 확보를 우선
- KPI는 트래픽보다 `입점`, `상담`, `전환`, `재계약` 중심으로 관리

## 2. 12주 실행 일정표

| 주차 | 핵심 목표 | 세부 실행 | 책임 |
|---|---|---|---|
| 1주 | 권역 선정 | 서울/경기, 부산/경남, 대구/경북 중 우선 권역 확정 | 대표/사업 |
| 2주 | 타깃 리스트업 | 시설 100곳, 상조 본사 20곳 리스트 작성 | 사업 |
| 3주 | 세일즈 자산 준비 | 시설 입점 랜딩, 시설 제안서, 상조 제안서 확정 | 사업/마케팅 |
| 4주 | 입점 영업 시작 | 시설 아웃바운드 1차 연락, 미팅 일정 확보 | 사업 |
| 5주 | 온보딩 체계화 | 사진/가격표/소개 템플릿, 등록 대행 프로세스 정리 | 운영 |
| 6주 | 콘텐츠 시작 | 지역/비용/비교 랜딩 10개 공개 | 마케팅 |
| 7주 | 시설 입점 확대 | 앵커 시설 미팅 집중, 1차 등록 완료 | 사업/운영 |
| 8주 | 상조 본사 미팅 | 파일럿 제안 미팅 3~5건 진행 | 대표/사업 |
| 9주 | 유입 실험 | 검색광고 소액 테스트, 랜딩 전환 측정 | 마케팅 |
| 10주 | 성공사례 확보 | 입점 시설 상담/유입 사례 정리 | 사업/운영 |
| 11주 | 유료 전환 실험 | 무료 -> 라이트/프리미엄 제안 시작 | 사업 |
| 12주 | 분기 리뷰 | 입점 수, 리드 수, 계약 수, 전환율 분석 | 대표/전팀 |

## 4. KPI 대시보드

### A. 시설 입점 KPI

| KPI | 정의 | 월 목표 | 비고 |
|---|---|---:|---|
| 신규 등록 시설 수 | 월 신규 입점 시설 수 | 10~20 | 권역별 분리 관리 |
| 앵커 시설 확보 수 | 지역 대표급 시설 입점 수 | 2~3 | 핵심 지표 |
| 프로필 완성률 | 등록 후 필수 정보 입력 완료 비율 | 80%+ | 사진/가격 포함 |
| 첫 문의 도달률 | 입점 후 첫 상담 발생 비율 | 50%+ | 입점 질 판단 |
| 무료 -> 유료 전환율 | 무료 시설 중 유료 전환 비율 | 10~20% | 2~3개월 누적 |

### B. 상조 제휴 KPI

| KPI | 정의 | 월 목표 | 비고 |
|---|---|---:|---|
| 본사 접촉 수 | 제안서 발송 또는 통화 완료 수 | 10+ | |
| 본사 미팅 수 | 실미팅 또는 데모 진행 수 | 3+ | |
| 파일럿 제안 수 | 조건 제안 완료 수 | 2+ | |
| 파일럿 계약 수 | 서면/구두 합의 완료 수 | 1+ | 분기 기준 |
| 재계약 의향률 | 파일럿 종료 전 긍정 응답 비율 | 50%+ | |

### C. 유저 유입 KPI

| KPI | 정의 | 월 목표 | 비고 |
|---|---|---:|---|
| 자연검색 유입 | SEO 기반 방문 수 | 지속 증가 | 핵심 채널 |
| 광고 유입 CPA | 상담 1건당 광고비 | 관리 필요 | 초기 테스트 |
| 비교함 저장률 | 방문 대비 비교함 사용 비율 | 5%+ | |
| AI상담 시작률 | 방문 대비 AI상담 시작 비율 | 3~8% | |
| 상담 신청 전환율 | AI상담 대비 상담 신청 비율 | 20%+ | |

## 5. 매출 KPI 시트

- 시설 라이트: `49,000원/월`
