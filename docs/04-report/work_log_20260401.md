### 2. 시설 이미지 폴백 수정

**문제**: 모든 장례식장이 동일한 대표 이미지로 표시
**원인**:
- `BAD_URL_PATTERNS`에 `/defaults/`가 포함 → DB에 의도적으로 배정한 기본 이미지 URL 거부
- charCode 합계 기반 해시 → mod 8 충돌 빈번

**수정** (`utils/facilityNormalizer.ts`):
- `/defaults/` BAD_URL_PATTERNS에서 제거 — DB 배정 기본 이미지 정상 허용
- 폴백 해시를 FNV-1a로 교체 — 결정론적 + 균일 분산
